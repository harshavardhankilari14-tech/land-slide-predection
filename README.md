# land-slide-predection
Developed a machine learning-based landslide prediction system that analyzes environmental factors such as rainfall, slope, soil type, and vegetation to identify high-risk areas. The project involves data preprocessing, basic model implementation, and prediction of landslide-prone zones to support early risk awareness.
# Landslide Prediction System

## Overview
This project is a machine learning-based system designed to identify potential landslide-prone areas using environmental data. The goal is to support early risk detection and improve disaster preparedness.

## Features
- Data preprocessing and analysis
- Prediction of landslide risk zones
- Basic model evaluation
- Simple and understandable implementation

## Technologies Used
- Python
- Machine Learning Concepts
- Data Processing

## How It Works
1. Collect environmental data such as rainfall, soil type, slope, and location factors.
2. Preprocess the data to remove inconsistencies and prepare it for modeling.
3. Apply a machine learning model to predict whether a region is at risk.
4. Evaluate results and classify areas as low-risk or high-risk.

## Project Structure
- `main.py` – Main execution file
- `data.csv` – Dataset used for training/testing
- `model.py` – Contains model logic (if separate)
- `README.md` – Project documentation
